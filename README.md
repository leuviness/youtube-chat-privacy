# youtube-chat-privacy

Page d'accueil et règles de confidentialité publiques de l'appli Google OAuth
« Youtube-chat » (projet Cloud `youtube-chat-499405`). Google les exige pour passer
l'appli en « In production » ; sans ça, le jeton YouTube expire au bout de 7 jours.

Publié par GitHub Pages : https://leuviness.github.io/youtube-chat-privacy/
Utilisé dans le dépôt privé `leuviness/youtube-chat` (README, « Réinstaller de zéro »).
